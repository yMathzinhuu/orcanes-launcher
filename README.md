Launcher leve e customizado para Minecraft 1.21.1 NeoForge com sincronização automática de mods, suporte a login Microsoft/Offline, visualizador de skins 3D e minigame integrado.

## 🚀 Recursos
* **Modpack Auto-Sync:** Sincroniza e limpa a pasta de mods automaticamente ao iniciar.
* **Skins 3D:** Visualizador e carregador de skins para CustomSkinLoader.
* **Flags Otimizadas:** Configuração de JVM pronta para reduzir o consumo desnecessário de RAM.
* **Sem frescuras:** Interface limpa e sólida.
